# 🎵 Proyecto Spotify (Recreación Interfaz)

Este proyecto es una recreación de la interfaz principal de **Spotify**, desarrollada con **HTML, CSS y Bootstrap 5**.  
El objetivo es practicar la maquetación web, la estructura de componentes reutilizables y el diseño responsive adaptable a escritorio y móvil.

---

## 🚀 Presentación

La página imita la experiencia visual de Spotify, incorporando elementos como:
- Una **cabecera** con logotipo, buscador y botones interactivos.
- Un **sidebar** con opciones de biblioteca, accesos y enlaces legales.
- Una sección de **carruseles dinámicos** que muestran canciones, artistas y álbumes populares.
- Un **footer** adaptado tanto para escritorio como para dispositivos móviles.

Todo el diseño está basado en el sistema de rejillas de Bootstrap y en el uso de **Google Fonts** y **Bootstrap Icons**, garantizando un estilo moderno y coherente.

---

## 🧭 Instrucciones de uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Hugobf10/Spotify_Trabajo.git

2. Abre la carpeta del proyecto:
   ```bash
   cd Spotify_Trabajo
   
3. Abre el archivo index.html en tu navegador o utiliza una extensión de servidor local como Live Server (VSCode).
4. Navega por la interfaz y explora los diferentes carruseles de canciones, artistas y álbumes.
